# Employee Attendance App

This is the Flutter mobile application for employees to manage their attendance.

## Features

- Login screen with username/password authentication
- Punch-in/out functionality  
- Attendance history display
- Responsive Material 3 design

## Architecture

### Folder Structure
```
lib/
├── main.dart            # Entry point
└── screens/
    └── login_screen.dart  # Login screen implementation
```

## How to Run

1. Navigate to the project directory:
   ```bash
   cd frontend/userapp
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Start development server:
   ```bash
   flutter run
   ```
