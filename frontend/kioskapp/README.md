# Attendance Kiosk App

This is the Flutter mobile application for attendance kiosks with face and fingerprint scanning.

## Features

- Face recognition scanning for attendance
- Fingerprint scanning alternative
- Real-time scanning feedback
- Material 3 design

## Architecture

### Folder Structure
```
lib/
├── main.dart            # Entry point
└── screens/
    └── face_scan_screen.dart  # Face scan screen implementation
```

## How to Run

1. Navigate to the project directory:
   ```bash
   cd frontend/kioskapp
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Start development server:
   ```bash
   flutter run
   ```
